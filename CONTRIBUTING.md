# Contributing

This repository uses task-driven development.

1. Select one approved `TASK-xxx`.
2. Create `task/TASK-xxx-short-slug`.
3. Update task status to `IN_PROGRESS` only after the branch exists.
4. Keep changes inside the task's allowed paths.
5. Run the stated verification commands.
6. Update project state, memory handoff and evidence.
7. Open a draft PR with the task number and real test results.
8. Merge only after acceptance criteria are checked.

Never submit secrets, real customer recordings, model weights, unlicensed avatar assets, contracts or raw business archives.
