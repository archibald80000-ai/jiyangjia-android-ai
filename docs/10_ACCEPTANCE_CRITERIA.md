# Acceptance criteria

## LiveTalking baseline

- Locked upstream checkout is reproducible.
- Service startup succeeds or exact blocker is documented.
- Official page is reachable.
- WHEP/WebRTC result is recorded.
- Core control APIs are tested with request/response evidence.
- Real GPU/model claims include hardware and logs.

## Android shell

- Release/debug APK is actually produced.
- Landscape immersive mode and local idle video work.
- Service URL and display mode are configurable.
- Network loss does not crash or blank the app.
- USB/default microphone behavior is recorded on the real device.
- Speaker output is audible and returns to idle.

## Model loop

- Mock end-to-end passes before paid APIs.
- Provider keys remain server-side.
- Timeout, error and cost behavior are tested.
- Answer text and speech match the same request ID.

## Mini knowledge

- Approved test set exists.
- Unsupported questions transfer safely.
- No medical promise or invented price appears.
- Evaluation report includes failures, not only successful examples.
