# MVP API Spec

Updated: 2026-08-06

Base path: `/api/v1`

## Common Headers

- `X-Device-Id`: configured Android display ID.
- `X-Request-Id`: UUID generated by client or gateway.
- `Authorization`: device token when enabled. Never log the value.

## Health

`GET /health`

Response:

```json
{
  "ok": true,
  "service": "jiyangjia-gateway",
  "version": "0.1.0",
  "providers": {
    "asr": "configured",
    "llm": "configured",
    "tts": "configured",
    "knowledge": "ready"
  }
}
```

## Client Config

`GET /client/config`

Response:

```json
{
  "display_mode": "idle_video_voice",
  "max_record_seconds": 20,
  "max_upload_bytes": 5242880,
  "accepted_audio_types": ["audio/wav", "audio/mp4", "audio/aac"],
  "subtitle_max_chars": 80,
  "idle_video_version": "local"
}
```

## Start Session

`POST /sessions`

Request:

```json
{
  "device_id": "store-screen-001",
  "app_version": "0.1.0",
  "android_version": "12"
}
```

Response:

```json
{
  "session_id": "sess_...",
  "request_id": "..."
}
```

## Dialogue Turn

`POST /dialogue/audio`

Content type: `multipart/form-data`

Fields:

- `session_id`
- `request_id`
- `audio`
- `content_type`
- `duration_ms`
- `sample_rate`
- `input_device`

Response:

```json
{
  "request_id": "uuid",
  "session_id": "sess_...",
  "transcript": {
    "text": "用户问题",
    "provider": "doubao",
    "confidence": null
  },
  "knowledge": {
    "status": "matched",
    "matches": [
      {"id": "faq-001", "confidence": 0.91, "status": "approved"}
    ]
  },
  "answer": {
    "text": "客服回答",
    "source": "faq_grounded_llm",
    "subtitles": ["客服回答"]
  },
  "tts": {
    "provider": "doubao",
    "content_type": "audio/mpeg",
    "audio_base64": "...",
    "duration_ms": 1800
  },
  "display": {
    "mode": "idle_video_voice",
    "return_to_idle": true
  }
}
```

```json
  "error": {
    "code": "PROVIDER_TIMEOUT",
    "message_for_user": "现在网络有点忙，请稍后再试。",
    "retryable": true,
    "details": {}
  }
}
```

## Provider Admin Diagnostics

`GET /admin/provider-status`

Protected endpoint for deployment diagnostics. It may report `configured/missing/disabled`, never secret values.
