# Open-source and asset compliance

## Code

Track every third-party repository, version, license and modification. Preserve notices required by upstream projects.

## Models

Model code licenses and model-weight licenses may differ. Do not assume Apache-2.0 on an integration repository grants commercial rights to every model weight.

## Person and voice assets

Obtain explicit permission for any real person's face or voice. Keep a provenance record for generated or commissioned avatars, source videos, clothes, logos, music and voice models.

## Publication

Before public demos, recorded videos or commercial deployment, review LiveTalking's current upstream notices and any watermark/attribution requirements, as well as each provider's terms.
