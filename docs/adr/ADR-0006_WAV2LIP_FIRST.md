# ADR-0006: Wav2Lip first

- Status: Superseded for Phase 1 by ADR-0008
- Date: 2026-08-05

## Decision

Reproduce Wav2Lip before evaluating MuseTalk or other renderers.

This remains relevant only for the future LiveTalking enhancement phase.

## Reason

It provides a simpler initial baseline and avoids concurrent model/dependency debugging.
