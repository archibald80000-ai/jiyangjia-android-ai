# Reasoning and decision gates

## Gate G0 — Before any implementation

- Fixed path confirmed.
- Git working tree understood.
- Secrets protected.
- One task authorized.

## Gate G1 — Before claiming LiveTalking works

- Locked commit checked out.
- Correct model/Avatar assets exist.
- Real service process and stream tested.
- Hardware/driver/model/FPS evidence recorded.

## Gate G2 — Before Android integration

- LiveTalking endpoint contracts are tested.
- Idle-video fallback behavior is defined.
- Installed Android SDK/JDK and device ABI are known.

## Gate G3 — Before paid provider calls

- Mock loop passes.
- Official current API contract is verified.
- Timeout, retry, cost cap and secret handling exist.

## Gate G4 — Before knowledge answers are treated as factual

- Source content is human-approved.
- Prohibited topics and transfer behavior pass tests.
- Mock markers are removed only after approval.

## Gate G5 — Before production deployment

- TLS, auth, firewall, retention, monitoring and rollback are tested.
- Actual Android device and store network pass acceptance.
- Asset/license review is complete.
