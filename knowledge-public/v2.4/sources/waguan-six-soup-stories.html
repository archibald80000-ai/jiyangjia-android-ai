01

清润菌菇鸡瓦罐汤

清鲜平和，适合作为瓦罐六膳的第一口

土鸡、羊肚菌与干香菇组成简洁的鲜味结构，红枣去核后提供轻微回甘，姜片压住肉腥。相比多菌大锅汤，这一罐减少了杂菌种类，让味道更干净。

500ML 单罐配方
土鸡100g羊肚菌4g干香菇5g红枣2颗生姜2g枸杞3g
风味与时长
参考慢煨3小时。菌菇鲜香清楚，鸡汤醇厚度适中，尾段有枣香与轻微姜香。
查看完整做法
  1. 土鸡加姜片冷水焯水2分钟，温水冲净后沥干。
  2. 菌菇泡10分钟并冲洗干净，红枣去核。
  3. 瓦罐加500ml纯净水，放入鸡肉、菌菇、红枣和姜片，隔水慢煨约2小时50分钟。
  4. 最后10分钟加入枸杞，少量盐调味。

食养故事｜市井人家的四季家常瓦罐

旧时汤铺不一定有名贵材料，却总会备着晒干的香菇和当日鸡肉。老人胃口清淡，小孩喜欢菌菇鲜味，一罐汤正好两代人都能接受。它没有浓烈草本味，是一家人随时都愿意点的家常款。

员工介绍一句话：“这款是土鸡配羊肚菌和香菇，鲜味清楚、药材味轻，第一次尝瓦罐汤可以先选它。” 菌类过敏者不可食用，容易腹泻者应谨慎选择。
02

温养气血生姜鸡瓦罐汤

以生姜为主角的温暖辛香

这款配方只有土鸡、生姜、红枣和枸杞，结构简单。30g生姜拍裂后慢煨，辛香进入汤里，红枣柔和姜的锋利感，适合本身就喜欢姜味的客人。

500ML 单罐配方
土鸡100g生姜30g红枣2颗枸杞3g
风味与时长
参考慢煨3.5小时。入口温热，生姜辛香明显，鸡汤和红枣让整体更圆润。
查看完整做法
  1. 土鸡冷水焯水，冲净血沫。
  2. 生姜拍裂，让香气更容易进入汤中。
  3. 鸡肉、生姜与红枣入罐，加500ml纯净水，隔水慢煨约3小时20分钟。
  4. 最后10分钟加入枸杞，少量盐调味。

食养故事｜寒天归家的一盅姜鸡汤

旧时赶路的人迎着冷风回家，灶台上最先闻到的往往是姜香。家人把姜拍裂，与鸡肉同炖，等汤烧好再喊人吃饭。那一盅汤的意义很简单：外面再冷，回家总有热汤。

员工介绍一句话：“这款姜味比较明显，喝起来暖口，适合平时就喜欢生姜味的人。” 容易上火、咽喉不适、发热或特殊健康状况者，应先确认是否适合。
03

轻祛湿茯苓猪肚鸡瓦罐汤

猪肚、鸡肉与炒薏米的谷物香

土鸡和猪肚形成双肉料汤底，炒薏米带坚果般的熟谷香，茯苓味道清淡，姜片用于去腥。汤感比纯鸡汤更厚，却没有复杂香料。

500ML 单罐配方
土鸡70g猪肚40g炒薏米8g茯苓6g生姜2片
风味与时长
参考慢煨约2.8小时。猪肚弹韧、鸡汤鲜，炒薏米增加熟谷香和轻微颗粒感。
查看完整做法
  1. 猪肚用盐和面粉反复搓洗去黏液，彻底冲净。
  2. 猪肚与土鸡一同冷水焯水，再冲净浮沫。
  3. 炒薏米、茯苓浸泡10分钟。
  4. 全部食材入罐，加500ml纯净水，隔水慢煨约2小时40分钟，出锅前少量加盐。

食养故事｜潮湿雨季里的谷香瓦罐

岭南雨季里，人们爱把薏米先炒香，再与猪肚、鸡肉一起煨。火候一到，猪肚的肉香与薏米的熟谷香交织，汤不油腻，配一碗米饭就很满足。它是一盅带地方饮食习惯的家常汤。

员工介绍一句话：“这款有猪肚和鸡肉，汤感更厚，炒薏米会带一点熟谷香。” 薏米对孕期、经期、尿频或有特殊健康状况者是否适合，应先咨询专业人士。
04

轻补元气参芪鸡瓦罐汤

参芪草本香与鸡汤相融

土鸡配黄芪、党参、红枣和枸杞，去掉了当归，减少浓重味道。黄芪和党参带来清楚但不过分复杂的草本香，红枣让汤味更柔和。

500ML 单罐配方
土鸡100g黄芪6g党参5g红枣2颗枸杞3g
风味与时长
参考慢煨2小时。鸡汤鲜味中带参芪草本香，红枣与枸杞形成轻微回甘。
查看完整做法
  1. 土鸡冷水焯水，冲净备用。
  2. 黄芪、党参与红枣清洗后浸泡10分钟。
  3. 食材入罐，加500ml纯净水，隔水慢煨约1小时50分钟。
  4. 最后10分钟加入枸杞，少量盐调味。

食养故事｜劳心人桌边的一盅慢汤

故事里的幕僚每日伏案，吃饭总是匆忙。老厨没有给他做浓油重汤，而是用少量参芪与鸡肉慢煨，提醒他把用餐速度也慢下来。汤的草本香不浓，重点是一日三餐里留出一段安静时间。

员工介绍一句话：“这款是黄芪、党参配土鸡，草本香比菌菇汤明显，但配方比较精简。” 含黄芪、党参，正在用药、高血压、发热或特殊健康状况者应先咨询专业人士。
05

清补滋养纯鸽子瓦罐汤

鸽子汤底，带麦冬的清润微甘

这一罐不用鸡肉，以鸽子为汤底，配少量麦冬、红枣和枸杞。鸽肉鲜味细致，麦冬味道清淡，红枣让汤有自然甜香。

500ML 单罐配方
鸽子100g麦冬4g红枣2颗枸杞3g
风味与时长
参考慢煨2.2小时。鸽汤鲜味细腻，麦冬带清润口感，枣香轻柔。
查看完整做法
  1. 鸽子冷水焯水，去净血沫后冲洗。
  2. 麦冬与红枣简单冲洗，红枣可去核。
  3. 全部食材入罐，加500ml纯净水，隔水慢煨约2小时10分钟。
  4. 最后10分钟加入枸杞，少量盐调味。

食养故事｜挑灯夜读后的清汤

旧时书生挑灯夜读，夜深后不想吃太油腻，家人便留一盅清淡鸽汤。麦冬和红枣用量不多，只给鸽汤添一点清润与甜香。那是一份不打扰读书、也不让晚饭太沉重的夜间照料。

员工介绍一句话：“这款是纯鸽子汤底，味道比鸡汤细一点，配少量麦冬和红枣，整体清润微甘。” 对鸽肉或配料过敏者不可食用，特殊人群先咨询专业人士。
06

强筋山药排骨汤

不吃禽肉时，也有一罐家常排骨汤

猪肋排、山药、生姜和枸杞构成最家常的一罐。排骨汤香稳，山药慢煨后绵软，姜片去腥，适合不喜欢鸡肉或鸽子口感的人。

500ML 单罐配方
猪肋排100g山药30g枸杞3g生姜2片
风味与时长
参考慢煨2.5小时。排骨香醇，山药绵软，汤色清亮，草本味最轻。
查看完整做法
  1. 排骨冷水焯水，撇净浮沫后冲洗。
  2. 山药去皮切块，暂泡清水避免氧化发黑。
  3. 排骨、山药和姜片入罐，加500ml纯净水，隔水慢煨约2小时20分钟。
  4. 最后10分钟加入枸杞，少量盐调味。

食养故事｜山里劳作人家的排骨山药汤

樵夫不爱吃鸡，家里便用猪肋排替代。山药切得滚刀大块，与排骨一同入罐，慢慢煨到筷子能轻松夹开。没有复杂香料，只有排骨、山药和姜片，是最容易被家人接受的一款。

员工介绍一句话：“这款是排骨加山药，味道最家常，草本味也最轻，不喜欢鸡和鸽子可以选它。” 山药口感绵密，容易腹胀或消化不适者可少量尝试。
